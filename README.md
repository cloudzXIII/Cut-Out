# ![icon](assets/1x/mod_icon.png) Cut-Out - An Abandonia Add-on!

A Balatro mod founded by Bunnet with the help from the Abandonia Team, adding content that doesn't fit the base mod!

# Additions

Cut-Out currently adds support for Modded Face cards and their ranks, along with the Evolution Mechanic that can give improve baseline Jokers and their abilities


# Installation
- Requires [Abandonia](https://github.com/cloudzXIII/Abandonia)

Get the latest development version from [here](https://github.com/cloudzXIII/Cut-Out/archive/refs/heads/main.zip), then download and extract the zip into the Mods folder.
